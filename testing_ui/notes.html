Plaintext means information is sent in readable, unencrypted form. Anyone inspecting network traffic can read the message word for word.

QuMail's 3 Security Levels Overview

Level 1

Plaintext Transmission

  • What it does: Transmits raw readable message without payload encryption.
  • What travels: Cleartext JSON payload + Dilithium digital signature.
  • Attacker sees: Full readable email body.
  • Bob receives: Direct readable message.
  • Purpose: Baseline demonstration of insecure transmission.
Level 2

Kyber-1024 KEM + AES-256-GCM

  • What it does: Establishes post-quantum shared secret via Kyber KEM and encrypts body via AES-GCM.
  • What travels: Kyber ciphertext + AES ciphertext + Nonce + Signature.
  • Attacker sees: Scrambled hex ciphertexts (no plaintext exposed).
  • Bob receives: Decapsulates shared secret to decrypt email.
  • Purpose: Complete Post-Quantum Secure Email Flow.
Level 3

Quantum One-Time Pad (OTP)

  • What it does: Encrypts payload byte-by-byte using bitwise XOR with single-use key.
  • What travels: OTP ciphertext (+ debug key in demo mode).
  • Attacker sees: Random byte sequence.
  • Bob receives: Re-applies XOR key to recover original bytes.
  • Purpose: Mathematical perfect secrecy simulation.
